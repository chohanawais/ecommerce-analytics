# E-commerce Business Intelligence Project


## Product Overview
This project analyzes e-commerce sales data using Python, Pandas, SQLite, and Matplotlib.


## Key Features
- Sales data processing
- Revenue calculation
- Cost and profit analysis
- SQLite database integration
- Top-selling product analysis
- Sales and profit visualization

## Technologies Used
- Python
- Pandas
- SQLite
- Matplotlib
- SQL

## Project Files
- sales_to_database.py
- slaes_report.py
- top_products.py
- sales_chart.py
- data/sales.csv

## Business Values
This project helps analyze sales performance,
identify profitable products, and support
data-driven business decisions.
